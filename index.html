计算口径

  1. 指标与时间原点。展示首次故障的生存曲线 S(t)=P（首次故障年龄 > t)。时间原点为投用日，t 为设备年龄（天）。
  2. 延迟进入（左截断）。设备自「开始观测」起才进入在险集合，L = 开始观测 − 投用。投用到进入观测之间不计入在险——该设备在 L 之前的故障本就不可观测；若记录显示故障早于开始观测，按规则 Q5 隔离。
  3. 右删失。观测窗口末 = min（退役日期， 数据观测截止， 统一观测截止）。窗口内未故障的设备在窗口末右删失。没有故障不代表永不故障，只是观测到此为止。故障日期晚于窗口末的记录同样按窗口末删失（修正记录）。
  4. 同一时点的处理约定。统一按「先进入 → 再故障 → 后删失」：t 时刻进入的设备计入 t 的在险数；t 时刻删失的设备也计入 t 的在险数（视为故障之后离开）。每个时点的进入 / 在险 / 故障 / 删失四列在「计算明细」中逐行可查。
  5. 置信区间。Greenwood 方差 + log-log 变换的 95% 区间。尾部在险数变小后区间会显著变宽——请以区间宽度而非点估计判断尾部。
  6. 尾部不外推。曲线只画到各型号最后一个退出（故障或删失）时点，以竖线端标结束；样本耗尽后不再延伸。各时点剩余在险数见曲线下方风险表。

隔离规则（先隔离、不进入分析，全部记录可在「隔离与修正」复查）

规则内容
Q1必需日期缺失或无法解析
Q2日期倒置：退役日期早于投用日期
Q3日期倒置：首次故障早于投用日期
Q4日期倒置：退役日期早于开始观测（设备从未进入可观测状态）
Q5首次故障早于可观察范围（故障日期早于开始观测）
Q6日期倒置：退役日期早于首次故障
Q7日期倒置：数据观测截止早于投用日期

不属于隔离的情形：开始观测缺失或早于投用（按投用日进入）、数据观测截止缺失（按统一截止）、 故障日期晚于观测窗口末（按窗口末删失）——这些进入「修正记录」。开始观测晚于整个观测窗口的设备不进入分析，列于「未进入分析」。

退役删失的假设与潜在偏差

本页把退役视为与故障风险独立的删失：假设被退役设备此后的故障风险与仍在观测的同类设备相同。 若实际并非如此——例如老化或亚健康设备被优先退役——高风险个体会提前离开样本，剩余在险集合风险偏低， S(t) 会被高估（曲线偏乐观）；反之若退役政策优先保留老旧设备，则方向相反。 该假设无法由本数据自身检验，解读曲线时请保留这一不确定性；如退役与工况强相关，建议按工况分层后分别绘制。

不要把型号间差异读作因果

型号间曲线差异可能来自批次构成、投用时间、工况、维护策略等混杂因素，而非型号本身。 示例数据中 BX-200 自 2023Q3 起的批次被刻意设为更差——用批次筛选可以看到曲线随之改变。 本页不做假设检验；曲线差异只是描述性结果，不构成「型号导致可靠性差异」的因果结论。

如何复查每一步计算

  1. 重新生成示例数据：python3 scripts/generate_data.py（固定随机种子，可复现）。
  2. 独立复算：python3 scripts/verify_km.py data/sample_devices.csv --out out， 得到每个型号的风险集与曲线明细（与页面「计算明细」同格式）。
  3. 页面「导出计算明细 CSV」（全部型号、全部批次、截止=数据自带截止时）与 out/km_steps_all.csv 可直接 diff。
  4. 自动对照：node tests/compare_engines.mjs 会逐时点比对 JS 与 Python 两套实现； 单元测试：node --test tests/test_survival.mjs、python3 -m unittest tests.test_verify_km。
